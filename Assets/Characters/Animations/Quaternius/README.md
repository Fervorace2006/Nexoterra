# Animaciones Quaternius / ActionForge

Sets de animación humanoides usados por los controladores de `Assets/NexoterraWorld/Locomotion`:

- `Player`: jugador masculino y femenino.
- `Enemy1`: soldado enemigo.
- `SirBlack`: jefe Sir Black.

Cada set incluye 10 animaciones: idle, walk, sprint, apuntado, idle de pistola, recarga,
disparo, voltereta y nado (avance e idle).

Origen: ActionForge / Quaternius, dedicadas al dominio público bajo CC0 1.0.
No requieren atribución, pero se conserva aquí por trazabilidad.

Los FBX se importan como Humanoid para poder reutilizar el mismo clip con los avatares
de los modelos `Assets/Characters/Rigged/*`.
